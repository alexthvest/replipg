# Новые варианты постепенного крафта

**Выбран вариант A.** После дополнительного эксперимента с выдуманными материалами пользователь подтвердил его применение. Английский текст A перенесён в генератор без изменений; ниже сохранены исходные результаты сравнения.

Три новых промпта проверены на свежих цепочках из текущего каталога. Каждый результат показан без исправления названия и описания. Старые подборки удалены; здесь нет прежних сгенерированных подкладок или других готовых тестовых предметов.

## Варианты для выбора

| Вариант | Идея | Полный промпт |
| --- | --- | --- |
| A — Ступени обработки | Сырьё становится материалом, затем компонентом, узлом и готовой вещью | [Текст A](prompts/A-stages.txt) |
| B — Готовность к сборке | Если нужные функции и материалы уже есть, завершить вещь; иначе получить достижимый компонент | [Текст B](prompts/B-readiness.txt) |
| C — Сочетание свойств | Найти новое свойство взаимодействующих материалов, из которого вырастает следующий компонент или вещь | [Текст C](prompts/C-properties.txt) |

Общее правило: количество каждого материала ограничивает конструкцию отдельно. Лишняя шерсть не заменяет кожу; больший запас кожи может позволить большую площадь покрытия. Выход остаётся одним предметом. Малого запаса должно хватать на меньшую вещь или компонент, а не давать отказ.

## Полнота генерации

| Вариант | Принято ответов | Отклонено ответов | Заблокировано зависимых шагов |
| --- | --- | --- | --- |
| A — Ступени обработки | 22 | 0 | 0 |
| B — Готовность к сборке | 22 | 0 | 0 |
| C — Сочетание свойств | 22 | 0 | 0 |

Принятый ответ прошёл проверку структуры, но это не оценка смысла. Отклонённый ответ не используется в следующих шагах. Заблокированный шаг не отправляется в модель, если нужный промежуточный предмет недоступен.

## Как устроены новые цепочки

- Глина и песок — простое начало из сырья.
- Ткань и шерсть → результат соединяется с нитками → полученный текстильный компонент сравнивается с разными количествами кожи.
- Шестерёнки и пружины → реальный результат соединяется с дакимакурой.
- Fumo и Neco-Arc проверяют сочетание развитых необычных предметов.

Внутри одного варианта и серии все проверки количества используют один и тот же текстильный компонент без правок. Между вариантами компоненты могут отличаться: сравниваются целые цепочки, а не только последний промпт. Фактические ингредиенты указаны в каждой строке — даже если вместо ожидаемой подкладки модель придумала сумку.
